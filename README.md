# Personality Test Builder

A modern web application for creating and interacting with custom personality assessments.

This project demonstrates the development of an interactive personality test builder where users can design, customize, and complete personality quizzes through a clean and responsive interface. Throughout development, multiple versions were created to refine the user experience, improve functionality, and expand customization options.

## Features

- 🧠 Create custom personality tests
- ❓ Multiple question support
- 🎯 Score-based personality results
- 📝 Customizable answer choices
- 📊 Automatic result calculation
- 📱 Responsive design
- ⚡ Fast and lightweight interface
- 🎨 Modern user interface
- 🧩 Multiple development iterations

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/endritngjelina/Personality-Test-Builder.git
```

### Run locally

Open the latest HTML file directly in your browser, or launch a local development server.

Using Python:

```bash
python -m http.server
```

Then visit:

```
http://localhost:8000
```

Alternatively, use the **Live Server** extension in Visual Studio Code.
